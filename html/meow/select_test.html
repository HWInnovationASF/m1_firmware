ทดสอบ select เป็น widget .msel ใน dialog

สิ่งที่ต้องเช็ค: คลิก select (Model/Mode/Baudrate/Parity/Function) → ต้องเป็นปุ่ม pill + panel ลอยแบบเดียวกับตาราง cmlall, เลือกได้, และเปลี่ยน Mode เป็น RTU/TCP/UDP แล้ว block ต้องสลับตาม.
